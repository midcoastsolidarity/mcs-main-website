## Project Overview

This repo contains a simple website for the Maine-based Midcoast Solidarity organization. It is built with vanilla HTML and CSS. There are no frameworks, no build steps, and [**NO JAVASCRIPT**](https://disable-javascript.org/) (in deployment, but the maintainers still use `npm` for dev tooling). Just open `index.html` in a browser.

## Viewing the site

Open `index.html` in any browser and you are looking at the live site. Every other page opens the same way.

If you want live reloading while editing, serve the folder with any static HTTP server:

```bash
python -m http.server 8000
# or
npx serve
# or use your favorite live preview/server IDE extension
```

## Shared styles, header, and footer

Every page links `css/style.css`, and a style that only one page needs goes in a small `<style>` tag on that page. The header (with the top bar) and the footer are copied into each page, so any HTML file still opens on its own. To change the top bar, edit it in `index.html`, `data_policy_092326.html`, and `handbook_101525.html`. `npm run lint:shared` tells you if you missed one, and CI runs it too. [CONTRIBUTING.md](CONTRIBUTING.md#page-conventions) covers adding a page.
